# Cuttle Landing Page & Download Portal

This directory contains the standalone, static marketing and download portal for **Cuttle**, the offline Windows right-click file converter.

## Features
- **100% Offline Privacy Guarantee**: Highlights local conversion, zero network calls in engine, and GPL-3.0 transparency.
- **Interactive Windows 11 Context Menu Preview**: Visual demonstration of right-click conversion verbs.
- **Direct Download Links**: One-click installer (`.exe`) and portable archive (`.zip`).
- **Package Manager Commands**: One-click copy for `winget`, `scoop`, and `chocolatey`.
- **Format Explorer**: Live category filtering for Documents, Images, Video, and CAD.
- **Verification Details**: PowerShell commands for SHA256 integrity verification.

## Deployment
Can be served statically by any web server or deployed directly to GitHub Pages from the repository settings (`/site` or `gh-pages` branch).
Zero npm dependencies, zero build scripts required.
