1. The idea

You right-click. Morph converts. That’s it.

Normally, turning a video into music means searching Google, finding a website, uploading your file, waiting, and downloading it back. Morph removes all of that. It lives inside the menu you already use.

Morph shows only things that make sense for a video: audio, GIF, another video type. It will never offer “convert to Word” on a video.

No window to find, no account to make. Right-click, pick, done.

2. Behind the click

What happens in the 2 seconds after you click

  1. The menu only passes a message: “please turn these files into MP3”. It does no heavy work, so your File Explorer never freezes.
  2. The helper is a small program that stays quietly in the background. Because it is already awake, your click feels instant.
  3. The engine checks what the file really is (not just its name), picks the best tool, and runs it.
  4. The result is a brand new file placed beside the original. A pop-up tells you it’s done.
3. The tools inside

Morph is the waiter. Free tools are the chefs.

Great free programs already convert files perfectly well. The catch is that they need typed commands, so normal people can’t use them. Morph is the friendly front desk.

FFmpeg

Chef for video and audio. MP4 to MP3, GIFs, and more.

LibreOffice

Chef for office files. Word, PowerPoint and Excel into PDF. It’s large, so it’s an optional download.

Pandoc

Chef for text. Markdown, web pages, Word and plain text.

Image tools

Chef for photos. PNG, JPG, WEBP, and iPhone HEIC photos.

How good is each result? Morph tells you honestly with a label:

Lossless nothing lost   Lossy a little detail lost, like MP3   Best effort may need touch-ups, like PDF to Word

Why is PDF to Word “best effort”?A PDF is like a photo of a page: it knows where each letter sits, but not what a paragraph or a table is. Every converter has to guess. So Morph tells you up front instead of pretending it’s perfect.
4. Trust

How we keep your files from getting damaged

No converter can promise perfect results. What Morph can promise is that your original is never touched, and that you never get a broken half-file.

  • If the check fails, the temp file is deleted. You never see a broken file.
  • If a file with the same name exists, Morph adds a number. It never overwrites.
  • Tests compare the original before and after every conversion. They must be identical.

6. Reality check

What will go wrong, and the plan for each

Windows 11 hides the menu behind “Show more options”Plan: launch with the classic menu, then build the proper top-level entry in a later phase. The first-run screen shows users where to look in the meantime.
Windows warns “protected your PC” on unsigned appsPlan: sign the app, publish through winget, and share file fingerprints (hashes) so anyone can verify the download.
Antivirus wrongly flags the appPlan: build the app in public automated builds, sign it, and report false alarms to the antivirus companies.
First click feels slowPlan: keep the small helper running in the background so there is no wake-up delay.
PDF to Word looks messy, DWG drawings are locked-up formatsPlan: ship them last, label them “best effort”, and keep a public page showing what works well and what doesn’t. For DWG, only use tools whose license allows it, and never bundle the ones that don’t.
The app gets bigPlan: core tools only in the main download. Large extras (LibreOffice, OCR, DWG) are optional downloads.
Strange files: huge, password-protected, broken, open in another app, odd namesPlan: check disk space first, ask for passwords, retry once for locked files, support long and non-English names, and test all of this on purpose with a pile of nasty sample files.
Files from strangers can be hostilePlan: keep tools updated, set time limits, stop runaway programs completely, and block internet access for the converters.
Everyone asks for a new formatPlan: formats are simple entries in a list, so community contributors can add them with a test file.
7. Getting it onto computers

How people download and install it

  1. GitHub Releases. An installer, a no-install zip, and a fingerprint file. Built automatically every time you tag a version.
  2. winget. Windows’ built-in app installer. People type one line, or you add a button, and updates become easy.
  3. Your website. A big Download button, a short demo GIF, and one clear promise: “your files never leave your PC”.
  4. Optional: Microsoft Store and Scoop/Chocolatey. Extra reach. Check the Store’s current rules for apps that add menu entries first.
The installer must: work without admin rights, remove every trace when uninstalled, and download big extras only when the user agrees, with the size shown first.
8. Build order

Small steps, each one tested before the next

Phase 0Talk to 10 people. Pick the top conversions.
Phase 1Engine on the command line: video, audio, images.
Phase 2Right-click menu, helper, installer.
Phase 3Office files to PDF, folders.
Phase 4Windows 11 top menu, speed.
Phase 5PDF to Word, OCR, DWG.
Phase 6Signing, winget, beta, launch.

The rule that saves the project: ship the boring, reliable parts first. A small tool that never breaks earns more trust than a big one that sometimes does. The full details live in the PRD, TRD and phase plan doc.
