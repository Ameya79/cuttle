# Benchmarking and Performance Invariants

1. **Empirical Quality & Fidelity Tracking**:
   - Every conversion category must have quantifiable accuracy measurements:
     - **Documents**: Character / token similarity ratio (`difflib.SequenceMatcher`), structural element preservation, and validation pass rate.
     - **Images**: Bit-identical comparison (`ImageChops.difference`) for lossless paths; Peak Signal-to-Noise Ratio (PSNR dB) and file size reduction for lossy paths.
     - **Media**: Duration drift tolerance ($|duration_{dst} - duration_{src}| / duration_{src} < 0.1\%$) and audio stream extraction verification.

2. **Automated Reproducibility**:
   - All benchmark results documented in `docs/BENCHMARKS.md` must be generated by `scripts/benchmark.py` running against standardized fixtures.
   - The script must report system environment specifications (CPU, RAM, OS, tool versions) alongside benchmark results.

3. **Performance Regression Gate**:
   - Adapter optimizations or refactors must maintain or improve conversion latency; any regression exceeding 10% on benchmark fixtures requires justification.
